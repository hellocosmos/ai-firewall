# セキュリティ範囲と報告

[English](../en/security.md) · [한국어](../ko/security.md) · [简体中文](../zh-CN/security.md) · [日本語](../ja/security.md) · [Español](../es/security.md) · [Français](../fr/security.md)

脆弱性の疑いは、リビジョン、合成データによる再現手順、影響を添えて **hellocosmos@gmail.com** へ非公開で報告してください。公開 Issue に顧客データ、トークン、実際の資格情報を含めないでください。固定応答 SLA はありません。

保護境界は、信頼された署名付き転送ホップから明示的にルーティングされた対応 HTTP/MCP 通信です。ローカル例は合成デモであり、強化済み本番装置ではありません。

- 平文、ExtProc、mirror リスナーを信頼ネットワークと送信元に制限します。
- 署名鍵を保護・更新し、エージェントに渡さないでください。上流への経路を強制して迂回を防ぎます。
- inline 検査・認可の失敗は遮断します。別の mirror コレクターは原本を遮断できません。コンソール Mirror は同期経路なので検査器との通信障害時に遮断されます。
- 本文・時間の上限、マッピング、フィールドのマスキングを設定します。バッファ型 SSE は無制限のストリーミングではありません。
- ローカル SQLite の再送防止と監査保存は分散 HA や不変保存を保証しません。
- パターン・PII 検査には誤検知と見逃しがあります。
- 署名された送信元はユーザー・エージェントの本人証明ではありません。Enterprise には別の信頼された ID チェーンが必要です。

初期アカウントは `admin`、パスワードは `1234` です。設定で変更してください。管理はループバックにバインドします。ネットワーク設定は所有するデモ用 Envoy コンテナーを管理し、OS の NIC アドレス、物理経路、ファイアウォール規則は変更しません。認証、CSRF 検査、パスワードハッシュだけで合成デモが本番 IAM になるわけではありません。MIT は Community コードに適用され、非公開実装と顧客資産は含まれません。
